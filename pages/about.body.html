About DWG Plotter

DWG Plotter is a free, open-source tool for turning DWG and DXF drawings into PDFs, right in your web browser.

Why it exists

People are often sent a drawing they cannot open: a site manager without CAD software, a client checking a plan, an office printing a drawing set. Most online converters ask you to upload the file to their server, which is not acceptable for client or confidential drawings, and many return a blurry picture of the drawing instead of a proper plot. DWG Plotter reads the drawing on your own computer and prints each sheet the way it was drawn.

How it works

When you open a drawing, the page reads it with LibreDWG, an open-source DWG reader from the GNU project, compiled to run inside the browser. DXF files are read with dxf-parser. The page then draws each layout with its lineweights, linetypes and colours, and writes a vector PDF with pdf-lib. All of this happens in your browser tab. The file never leaves your computer.

Open source

The whole site is free software under the GNU General Public License v3. You can read the source code, check that nothing is uploaded, run your own copy, or suggest improvements. The libraries it uses are listed in the credits.

Contact

To report a drawing that does not print correctly, ask a question or suggest a feature, open an issue on GitHub. Please do not attach confidential drawings.
