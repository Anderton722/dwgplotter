AC1015: the AutoCAD 2000 DWG format

AC1015 is the version code of the AutoCAD 2000 DWG format. A drawing that starts with AC1015 was saved by AutoCAD 2000, 2000i and 2002, or by another CAD program set to that format. AutoCAD 2000, the first release to save it, introduced multiple layouts and lineweights, which plotting still depends on.

Which software opens an AC1015 file

Every AutoCAD and AutoCAD LT release from 2000 onwards opens it, as do most other CAD programs that read DWG. AutoCAD R14 and older cannot open it and show an error instead.

Without AutoCAD, drop the file into the free DWG viewer: you can see every layout, zoom, measure and save it as a PDF. The file is read on your computer and never uploaded.

Why programs ask for AC1015

Almost every program that imports DWG or DXF, including older CNC, CAM and GIS software, can read the 2000 format. That is why export settings and file requests often say “AutoCAD 2000 DWG”. Only Release 14 and older cannot open it.

Saving a drawing as AC1015

In AutoCAD 2000 or later, choose Save As and set the file type to “AutoCAD 2000/LT2000 Drawing (*.dwg)”. To make it the default, change it under Options, Open and Save. Saving in an older format can simplify objects that format does not support, so keep the original too.

Questions

Which AutoCAD version is AC1015?

It is the AutoCAD 2000 DWG format, used by AutoCAD 2000, 2000i and 2002.

Can AutoCAD R14 open an AC1015 file?

No. Release 14 reads only up to AC1014. View the drawing in a browser instead, or convert it to PDF.

How do I check whether my file is AC1015?

Drop it into the DWG version checker, or open it in a plain text editor: the first six characters are the version code.

Do DXF files use the same AC1015 code?

Yes. A DXF file stores the same code after $ACADVER near the top, so a DXF marked AC1015 is in the 2000 format.
