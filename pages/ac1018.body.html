AC1018: the AutoCAD 2004 DWG format

AC1018 is the version code of the AutoCAD 2004 DWG format. A drawing that starts with AC1018 was saved by AutoCAD 2004 to 2006, or by another CAD program set to that format. AutoCAD 2004, the first release to save it, introduced true colour and colour books.

Which software opens an AC1018 file

Every AutoCAD and AutoCAD LT release from 2004 onwards opens it, as do most other CAD programs that read DWG. AutoCAD 2002 and older cannot open it and show an error instead.

Without AutoCAD, drop the file into the free DWG viewer: you can see every layout, zoom, measure and save it as a PDF. The file is read on your computer and never uploaded.

Opening it in an older AutoCAD

Ask whoever sent the file to save a copy in an older format: Save As, then pick the “AutoCAD 20xx Drawing” file type that matches your release, such as “AutoCAD 2000/LT2000 Drawing (*.dwg)”. If you only need to look at or print the drawing, converting it to PDF is quicker.

Saving a drawing as AC1018

In AutoCAD 2004 or later, choose Save As and set the file type to “AutoCAD 2004/LT2004 Drawing (*.dwg)”. To make it the default, change it under Options, Open and Save. Saving in an older format can simplify objects that format does not support, so keep the original too.

Questions

Which AutoCAD version is AC1018?

It is the AutoCAD 2004 DWG format, used by AutoCAD 2004 to 2006.

Can AutoCAD 2002 open an AC1018 file?

No. AutoCAD 2002 reads only up to AC1015. Save the drawing as “AutoCAD 2000/LT2000 Drawing (*.dwg)”, or view it in a browser instead.

How do I check whether my file is AC1018?

Drop it into the DWG version checker, or open it in a plain text editor: the first six characters are the version code.

Do DXF files use the same AC1018 code?

Yes. A DXF file stores the same code after $ACADVER near the top, so a DXF marked AC1018 is in the 2004 format.
