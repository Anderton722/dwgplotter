AC1024: the AutoCAD 2010 DWG format

AC1024 is the version code of the AutoCAD 2010 DWG format. A drawing that starts with AC1024 was saved by AutoCAD 2010 to 2012, or by another CAD program set to that format. AutoCAD 2010, the first release to save it, also introduced parametric constraints and mesh modelling.

Which software opens an AC1024 file

Every AutoCAD and AutoCAD LT release from 2010 onwards opens it, as do most other CAD programs that read DWG. AutoCAD 2009 and older cannot open it and show an error instead.

Without AutoCAD, drop the file into the free DWG viewer: you can see every layout, zoom, measure and save it as a PDF. The file is read on your computer and never uploaded.

Opening it in an older AutoCAD

Ask whoever sent the file to save a copy in an older format: Save As, then pick the “AutoCAD 20xx Drawing” file type that matches your release, such as “AutoCAD 2007/LT2007 Drawing (*.dwg)”. If you only need to look at or print the drawing, converting it to PDF is quicker.

Saving a drawing as AC1024

In AutoCAD 2010 or later, choose Save As and set the file type to “AutoCAD 2010/LT2010 Drawing (*.dwg)”. To make it the default, change it under Options, Open and Save. Saving in an older format can simplify objects that format does not support, so keep the original too.

Questions

Which AutoCAD version is AC1024?

It is the AutoCAD 2010 DWG format, used by AutoCAD 2010 to 2012.

Can AutoCAD 2009 open an AC1024 file?

No. AutoCAD 2009 reads only up to AC1021. Save the drawing as “AutoCAD 2007/LT2007 Drawing (*.dwg)”, or view it in a browser instead.

How do I check whether my file is AC1024?

Drop it into the DWG version checker, or open it in a plain text editor: the first six characters are the version code.

Do DXF files use the same AC1024 code?

Yes. A DXF file stores the same code after $ACADVER near the top, so a DXF marked AC1024 is in the 2010 format.
