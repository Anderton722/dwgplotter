AC1015: das DWG-Format von AutoCAD 2000

AC1015 ist der Versionscode des DWG-Formats von AutoCAD 2000. Eine Zeichnung, die mit AC1015 beginnt, wurde mit AutoCAD 2000, 2000i und 2002 gespeichert oder mit einem anderen CAD-Programm, das auf dieses Format eingestellt war. AutoCAD 2000, die erste Version, die es speicherte, führte mehrere Layouts und Linienstärken ein, auf denen das Plotten bis heute beruht.

Welche Software eine AC1015-Datei öffnet

Jede Version von AutoCAD und AutoCAD LT ab 2000 öffnet sie, ebenso die meisten anderen CAD-Programme, die DWG lesen. AutoCAD R14 und älter können sie nicht öffnen und zeigen stattdessen einen Fehler.

Ohne AutoCAD ziehen Sie die Datei in den kostenlosen DWG-Viewer: Sie sehen jedes Layout, können zoomen, messen und als PDF speichern. Die Datei wird auf Ihrem Computer gelesen und nie hochgeladen.

Warum Programme AC1015 verlangen

Fast jedes Programm, das DWG oder DXF importiert, auch ältere CNC-, CAM- und GIS-Software, liest das 2000-Format. Deshalb steht in Exporteinstellungen und Dateianfragen oft „AutoCAD-2000-DWG“. Nur Release 14 und älter können es nicht öffnen.

Eine Zeichnung als AC1015 speichern

Wählen Sie in AutoCAD 2000 oder neuer Speichern unter und den Dateityp „AutoCAD 2000/LT2000-Zeichnung (*.dwg)“. Als Standard legen Sie ihn unter Optionen, Öffnen und Speichern fest. Beim Speichern in einem älteren Format können Objekte vereinfacht werden, die dieses Format nicht kennt. Behalten Sie also auch das Original.

Fragen

Welche AutoCAD-Version ist AC1015?

Es ist das DWG-Format von AutoCAD 2000, verwendet von AutoCAD 2000, 2000i und 2002.

Kann AutoCAD R14 eine AC1015-Datei öffnen?

Nein. Release 14 liest nur bis AC1014. Sehen Sie die Zeichnung im Browser an oder wandeln Sie sie in PDF um.

Wie prüfe ich, ob meine Datei AC1015 ist?

Ziehen Sie sie in den DWG-Versionsprüfer oder öffnen Sie sie in einem Texteditor: Die ersten sechs Zeichen sind der Versionscode.

Verwenden DXF-Dateien denselben Code AC1015?

Ja. Eine DXF-Datei speichert denselben Code nach $ACADVER am Anfang. Eine als AC1015 markierte DXF ist also im 2000-Format.
