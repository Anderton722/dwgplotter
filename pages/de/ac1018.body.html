AC1018: das DWG-Format von AutoCAD 2004

AC1018 ist der Versionscode des DWG-Formats von AutoCAD 2004. Eine Zeichnung, die mit AC1018 beginnt, wurde mit AutoCAD 2004 bis 2006 gespeichert oder mit einem anderen CAD-Programm, das auf dieses Format eingestellt war. AutoCAD 2004, die erste Version, die es speicherte, führte True Color und Farbbücher ein.

Welche Software eine AC1018-Datei öffnet

Jede Version von AutoCAD und AutoCAD LT ab 2004 öffnet sie, ebenso die meisten anderen CAD-Programme, die DWG lesen. AutoCAD 2002 und älter können sie nicht öffnen und zeigen stattdessen einen Fehler.

Ohne AutoCAD ziehen Sie die Datei in den kostenlosen DWG-Viewer: Sie sehen jedes Layout, können zoomen, messen und als PDF speichern. Die Datei wird auf Ihrem Computer gelesen und nie hochgeladen.

In einem älteren AutoCAD öffnen

Bitten Sie den Absender, eine Kopie in einem älteren Format zu speichern: Speichern unter und den Dateityp „AutoCAD 20xx-Zeichnung“ wählen, der zu Ihrer Version passt, etwa „AutoCAD 2000/LT2000-Zeichnung (*.dwg)“. Wenn Sie die Zeichnung nur ansehen oder drucken müssen, ist die Umwandlung in PDF schneller.

Eine Zeichnung als AC1018 speichern

Wählen Sie in AutoCAD 2004 oder neuer Speichern unter und den Dateityp „AutoCAD 2004/LT2004-Zeichnung (*.dwg)“. Als Standard legen Sie ihn unter Optionen, Öffnen und Speichern fest. Beim Speichern in einem älteren Format können Objekte vereinfacht werden, die dieses Format nicht kennt. Behalten Sie also auch das Original.

Fragen

Welche AutoCAD-Version ist AC1018?

Es ist das DWG-Format von AutoCAD 2004, verwendet von AutoCAD 2004 bis 2006.

Kann AutoCAD 2002 eine AC1018-Datei öffnen?

Nein. AutoCAD 2002 liest nur bis AC1015. Speichern Sie die Zeichnung als „AutoCAD 2000/LT2000-Zeichnung (*.dwg)“ oder sehen Sie sie im Browser an.

Wie prüfe ich, ob meine Datei AC1018 ist?

Ziehen Sie sie in den DWG-Versionsprüfer oder öffnen Sie sie in einem Texteditor: Die ersten sechs Zeichen sind der Versionscode.

Verwenden DXF-Dateien denselben Code AC1018?

Ja. Eine DXF-Datei speichert denselben Code nach $ACADVER am Anfang. Eine als AC1018 markierte DXF ist also im 2004-Format.
