AC1021: das DWG-Format von AutoCAD 2007

AC1021 ist der Versionscode des DWG-Formats von AutoCAD 2007. Eine Zeichnung, die mit AC1021 beginnt, wurde mit AutoCAD 2007 bis 2009 gespeichert oder mit einem anderen CAD-Programm, das auf dieses Format eingestellt war. Es war das erste DWG-Format, das Text als Unicode speichert. Zeichnungen behalten ihre Zeichen also in jedem Alphabet.

Welche Software eine AC1021-Datei öffnet

Jede Version von AutoCAD und AutoCAD LT ab 2007 öffnet sie, ebenso die meisten anderen CAD-Programme, die DWG lesen. AutoCAD 2006 und älter können sie nicht öffnen und zeigen stattdessen einen Fehler.

Ohne AutoCAD ziehen Sie die Datei in den kostenlosen DWG-Viewer: Sie sehen jedes Layout, können zoomen, messen und als PDF speichern. Die Datei wird auf Ihrem Computer gelesen und nie hochgeladen.

In einem älteren AutoCAD öffnen

Bitten Sie den Absender, eine Kopie in einem älteren Format zu speichern: Speichern unter und den Dateityp „AutoCAD 20xx-Zeichnung“ wählen, der zu Ihrer Version passt, etwa „AutoCAD 2004/LT2004-Zeichnung (*.dwg)“. Wenn Sie die Zeichnung nur ansehen oder drucken müssen, ist die Umwandlung in PDF schneller.

Eine Zeichnung als AC1021 speichern

Wählen Sie in AutoCAD 2007 oder neuer Speichern unter und den Dateityp „AutoCAD 2007/LT2007-Zeichnung (*.dwg)“. Als Standard legen Sie ihn unter Optionen, Öffnen und Speichern fest. Beim Speichern in einem älteren Format können Objekte vereinfacht werden, die dieses Format nicht kennt. Behalten Sie also auch das Original.

Fragen

Welche AutoCAD-Version ist AC1021?

Es ist das DWG-Format von AutoCAD 2007, verwendet von AutoCAD 2007 bis 2009.

Kann AutoCAD 2006 eine AC1021-Datei öffnen?

Nein. AutoCAD 2006 liest nur bis AC1018. Speichern Sie die Zeichnung als „AutoCAD 2004/LT2004-Zeichnung (*.dwg)“ oder sehen Sie sie im Browser an.

Wie prüfe ich, ob meine Datei AC1021 ist?

Ziehen Sie sie in den DWG-Versionsprüfer oder öffnen Sie sie in einem Texteditor: Die ersten sechs Zeichen sind der Versionscode.

Verwenden DXF-Dateien denselben Code AC1021?

Ja. Eine DXF-Datei speichert denselben Code nach $ACADVER am Anfang. Eine als AC1021 markierte DXF ist also im 2007-Format.
