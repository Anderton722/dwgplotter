AC1024: das DWG-Format von AutoCAD 2010

AC1024 ist der Versionscode des DWG-Formats von AutoCAD 2010. Eine Zeichnung, die mit AC1024 beginnt, wurde mit AutoCAD 2010 bis 2012 gespeichert oder mit einem anderen CAD-Programm, das auf dieses Format eingestellt war. AutoCAD 2010, die erste Version, die es speicherte, führte auch parametrische Abhängigkeiten und Netzmodellierung ein.

Welche Software eine AC1024-Datei öffnet

Jede Version von AutoCAD und AutoCAD LT ab 2010 öffnet sie, ebenso die meisten anderen CAD-Programme, die DWG lesen. AutoCAD 2009 und älter können sie nicht öffnen und zeigen stattdessen einen Fehler.

Ohne AutoCAD ziehen Sie die Datei in den kostenlosen DWG-Viewer: Sie sehen jedes Layout, können zoomen, messen und als PDF speichern. Die Datei wird auf Ihrem Computer gelesen und nie hochgeladen.

In einem älteren AutoCAD öffnen

Bitten Sie den Absender, eine Kopie in einem älteren Format zu speichern: Speichern unter und den Dateityp „AutoCAD 20xx-Zeichnung“ wählen, der zu Ihrer Version passt, etwa „AutoCAD 2007/LT2007-Zeichnung (*.dwg)“. Wenn Sie die Zeichnung nur ansehen oder drucken müssen, ist die Umwandlung in PDF schneller.

Eine Zeichnung als AC1024 speichern

Wählen Sie in AutoCAD 2010 oder neuer Speichern unter und den Dateityp „AutoCAD 2010/LT2010-Zeichnung (*.dwg)“. Als Standard legen Sie ihn unter Optionen, Öffnen und Speichern fest. Beim Speichern in einem älteren Format können Objekte vereinfacht werden, die dieses Format nicht kennt. Behalten Sie also auch das Original.

Fragen

Welche AutoCAD-Version ist AC1024?

Es ist das DWG-Format von AutoCAD 2010, verwendet von AutoCAD 2010 bis 2012.

Kann AutoCAD 2009 eine AC1024-Datei öffnen?

Nein. AutoCAD 2009 liest nur bis AC1021. Speichern Sie die Zeichnung als „AutoCAD 2007/LT2007-Zeichnung (*.dwg)“ oder sehen Sie sie im Browser an.

Wie prüfe ich, ob meine Datei AC1024 ist?

Ziehen Sie sie in den DWG-Versionsprüfer oder öffnen Sie sie in einem Texteditor: Die ersten sechs Zeichen sind der Versionscode.

Verwenden DXF-Dateien denselben Code AC1024?

Ja. Eine DXF-Datei speichert denselben Code nach $ACADVER am Anfang. Eine als AC1024 markierte DXF ist also im 2010-Format.
