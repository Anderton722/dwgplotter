AC1032: das DWG-Format von AutoCAD 2018

AC1032 ist der Versionscode des DWG-Formats von AutoCAD 2018. Eine Zeichnung, die mit AC1032 beginnt, wurde mit AutoCAD 2018 bis zur aktuellen Version gespeichert oder mit einem anderen CAD-Programm, das auf dieses Format eingestellt war. Es ist das bisher langlebigste DWG-Format: Alle Versionen seit 2018 speichern noch darin, die meisten heutigen Zeichnungen sind also AC1032.

Welche Software eine AC1032-Datei öffnet

Jede Version von AutoCAD und AutoCAD LT ab 2018 öffnet sie, ebenso die meisten anderen CAD-Programme, die DWG lesen. AutoCAD 2017 und älter können sie nicht öffnen und zeigen stattdessen einen Fehler.

Ohne AutoCAD ziehen Sie die Datei in den kostenlosen DWG-Viewer: Sie sehen jedes Layout, können zoomen, messen und als PDF speichern. Die Datei wird auf Ihrem Computer gelesen und nie hochgeladen.

In einem älteren AutoCAD öffnen

Bitten Sie den Absender, eine Kopie in einem älteren Format zu speichern: Speichern unter und den Dateityp „AutoCAD 20xx-Zeichnung“ wählen, der zu Ihrer Version passt, etwa „AutoCAD 2013/LT2013-Zeichnung (*.dwg)“. Wenn Sie die Zeichnung nur ansehen oder drucken müssen, ist die Umwandlung in PDF schneller.

Eine Zeichnung als AC1032 speichern

Wählen Sie in AutoCAD 2018 oder neuer Speichern unter und den Dateityp „AutoCAD 2018-Zeichnung (*.dwg)“. Als Standard legen Sie ihn unter Optionen, Öffnen und Speichern fest. Beim Speichern in einem älteren Format können Objekte vereinfacht werden, die dieses Format nicht kennt. Behalten Sie also auch das Original. In allen aktuellen Versionen ist es bereits der Standard.

Fragen

Welche AutoCAD-Version ist AC1032?

Es ist das DWG-Format von AutoCAD 2018, verwendet von AutoCAD 2018 bis zur aktuellen Version.

Kann AutoCAD 2017 eine AC1032-Datei öffnen?

Nein. AutoCAD 2017 liest nur bis AC1027. Speichern Sie die Zeichnung als „AutoCAD 2013/LT2013-Zeichnung (*.dwg)“ oder sehen Sie sie im Browser an.

Wie prüfe ich, ob meine Datei AC1032 ist?

Ziehen Sie sie in den DWG-Versionsprüfer oder öffnen Sie sie in einem Texteditor: Die ersten sechs Zeichen sind der Versionscode.

Verwenden DXF-Dateien denselben Code AC1032?

Ja. Eine DXF-Datei speichert denselben Code nach $ACADVER am Anfang. Eine als AC1032 markierte DXF ist also im 2018-Format.
