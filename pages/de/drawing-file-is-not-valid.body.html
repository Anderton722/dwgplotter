„Zeichnungsdatei ist ungültig“: Ursachen und Lösungen

AutoCAD und andere CAD-Programme melden „Zeichnungsdatei ist ungültig“ („Drawing file is not valid“), wenn sie eine DWG nicht lesen können. Meist ist die Datei beschädigt, unvollständig oder gar keine echte DWG. So finden Sie heraus, was vorliegt, und retten die Zeichnung.

Datei hier öffnen

Zuerst prüfen, was die Datei ist

Ziehen Sie sie in den DWG-Versionsprüfer. Er liest nur die ersten Bytes, im Browser.

  • Er zeigt einen Versionscode wie AC1032 oder AC1027: Die Datei ist eine echte DWG, der Schaden liegt weiter innen. Weiter mit den Lösungen unten.
  • Er meldet, dass es keine Zeichnung ist: Die Datei wurde abgeschnitten, umbenannt, gepackt oder ist ein anderer Dateityp. Siehe „Die Datei ist keine echte DWG“.

Häufige Ursachen

Warum meldet eine DWG „Zeichnungsdatei ist ungültig“?

Die häufigsten Ursachen sind ein unvollständiger Download oder E-Mail-Anhang, eine Datei, die beim Absturz des Programms oder bei einem Netzwerkausfall gespeichert wurde, eine in .dwg umbenannte Datei, die eigentlich etwas anderes ist, und eine Datei aus Software, die das DWG-Format fehlerhaft schreibt.

Liegt es daran, dass die Datei zu neu ist?

Meist nicht. Eine Datei aus einer neueren Version führt normalerweise zu einer anderen Meldung über eine inkompatible Version. Siehe DWG mit inkompatibler Version erstellt.

Lösungen, von schnell bis aufwendig

1. Eine neue Kopie besorgen

Prüfen Sie die Dateigröße. Eine Zeichnung mit 0 Byte oder wenigen Kilobyte ist defekt. Bitten Sie den Absender, sie erneut zu schicken, gepackt oder per Download-Link, denn E-Mail-Systeme kürzen oder blockieren DWG-Anhänge manchmal.

2. In einem anderen Programm öffnen

Programme lesen beschädigte Dateien unterschiedlich. Probieren Sie den kostenlosen DWG-Viewer: Wenn er die Zeichnung öffnet, speichern Sie sie sofort als PDF.

3. Die Sicherungsdatei verwenden

AutoCAD legt den vorherigen Speicherstand als .bak-Datei im selben Ordner ab. Kopieren Sie sie, benennen Sie die Kopie von .bak in .dwg um und öffnen Sie sie. Verloren gehen nur die Änderungen seit dem letzten Speichern.

4. Nach einer automatischen Sicherung suchen

Automatische Sicherungen enden auf .sv$ und liegen im temporären Ordner, der in den Optionen des Programms eingestellt ist. Kopieren Sie eine, benennen Sie sie in .dwg um und öffnen Sie sie.

5. In AutoCAD „Wiederherstellen“ ausführen

Wenn Sie AutoCAD oder ein ähnliches CAD-Programm haben, verwenden Sie den Befehl WIEDERHERST (RECOVER) statt des normalen Öffnens. Er repariert, was möglich ist, und listet die Korrekturen auf. Danach PRÜFUNG (AUDIT) ausführen.

6. In eine neue Zeichnung einfügen

Wenn das Wiederherstellen scheitert, legen Sie eine neue Zeichnung an und fügen Sie die beschädigte Datei als Block oder als Xref ein. So lässt sich die Geometrie manchmal retten, wenn der Dateikopf beschädigt ist.

Die Datei ist keine echte DWG

  • Sie ist gepackt. Namen wie zeichnung.dwg.zip, oder eine Datei, die eigentlich ein ZIP ist, müssen zuerst entpackt werden.
  • Es ist eine andere Art .dwg. Einige fremde Programme verwenden ebenfalls die Endung .dwg.
  • Es ist eine umbenannte DXF oder PDF. Geben Sie ihr die richtige Endung zurück und öffnen Sie sie als solche.

Weitere Gründe, warum sich eine Zeichnung nicht öffnet: DWG lässt sich nicht öffnen.
