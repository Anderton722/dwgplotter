DWG mit inkompatibler Version erstellt? So öffnen Sie sie

Wenn Ihr CAD-Programm meldet, eine Zeichnung sei mit einer inkompatiblen Version erstellt worden, wurde die Datei in einem neueren DWG-Format gespeichert, als Ihre Software lesen kann. Sie können sie trotzdem ansehen, drucken oder in Ihre Version umwandeln lassen.

Hier kostenlos öffnen

Warum das passiert

Alle paar Jahre ändert AutoCAD das DWG-Format. Ein Programm öffnet sein eigenes Format und ältere, aber keine neueren. Eine Zeichnung aus AutoCAD 2018 oder neuer (Code AC1032) öffnet sich nicht in AutoCAD 2017 oder älter, und eine Zeichnung aus AutoCAD 2013 (AC1027) nicht in AutoCAD 2012.

Prüfen Sie das Format Ihrer Datei mit dem DWG-Versionsprüfer und vergleichen Sie es in der Tabelle der DWG-Versionen mit Ihrer Software.

Fünf Wege, sie zu öffnen

1. Im Browser ansehen und drucken

Der kostenlose DWG-Viewer liest alle Formate von R14 bis zum aktuellen Format 2018. Zoomen, Layer prüfen und jedes Layout als PDF speichern. Nichts wird hochgeladen.

2. Den Absender um eine ältere Version bitten

In AutoCAD: Datei > Speichern unter, dann unter „Dateityp“ ein älteres Format wählen, etwa „AutoCAD 2013/LT2013-Zeichnung“. Nennen Sie Ihre Version.

3. Mit einem kostenlosen DWG-Konverter umwandeln

Kostenlose Desktop-Konverter schreiben eine DWG in ein älteres Format um, einzeln oder ordnerweise. Behalten Sie das Original: Manche neueren Funktionen werden im älteren Format vereinfacht.

4. Stattdessen eine PDF oder DXF anfordern

Wenn Sie die Zeichnung nur ansehen oder drucken möchten, ist eine PDF einfacher. Zum Bearbeiten in anderer Software öffnet sich eine DXF in älterer Version in fast jedem CAD-Programm.

5. Die Software aktualisieren

Jedes AutoCAD ab 2018 öffnet alle aktuellen DWG-Dateien, denn das Format hat sich seit 2018 nicht geändert.

Fragen

Was bedeutet „mit einer inkompatiblen Version erstellt“?

Die Zeichnung wurde in einem neueren DWG-Format gespeichert als dem des Programms, das sie öffnen will. Die Datei selbst ist meist in Ordnung.

Welche AutoCAD-Version öffnet AC1032-Dateien?

AutoCAD 2018 und alle späteren Versionen. Siehe AC1032.

Kann ich eine neuere DWG ohne Umwandlung in einem älteren AutoCAD öffnen?

Nein. Die Datei muss in einem Format gespeichert oder in ein Format umgewandelt werden, das Ihre Version unterstützt.
