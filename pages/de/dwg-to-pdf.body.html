DWG in PDF umwandeln, kostenlos und im Browser

Öffnen Sie eine DWG-Zeichnung, wählen Sie aus, was gedruckt werden soll, und speichern Sie sie als PDF. Ohne AutoCAD, ohne Anmeldung, und Ihre Zeichnung wird nie hochgeladen.

Konverter öffnen

So wandeln Sie eine DWG-Datei in PDF um

  1. Öffnen Sie den Konverter und legen Sie Ihre DWG-Datei auf der Seite ab (oder klicken Sie, um sie auszuwählen).
  2. Die Seite listet alles auf, was gedruckt werden kann: jedes Layout (Blatt) der Datei sowie die Modellzeichnung.
  3. Haken Sie die gewünschten Blätter an. Wählen Sie Schwarzweiß oder Farbe.
  4. Klicken Sie auf PDF herunterladen. Mehrere Blätter können als ein gemeinsames PDF oder als einzelne Dateien gespeichert werden.

Was gedruckt wird

Layouts werden so gedruckt, wie sie in der Datei erscheinen, in ihrer eigenen Blattgröße, so wie ein geplotteter Planungssatz aussieht. Hat eine Datei keine Layouts, oder möchten Sie den Modellbereich, findet Smart-Plot die einzelnen Zeichnungen im Modell und lässt vereinzelte Striche weg, sodass Sie nicht eine winzige Zeichnung auf einer riesigen leeren Seite erhalten.

Sie können eine größere Vorschau jedes Blatts öffnen, um zu zoomen, Layer ein- und auszuschalten und Abstände zu messen, bevor Sie speichern.

Schwarzweiß oder Farbe

Schwarzweiß druckt jede Linie in Schwarz mit ihrer Linienstärke, wie ein monochromer Plotstil – die übliche Wahl für Ausgabepläne. Farbe behält die Farben der Zeichnung bei.

Papierformat

Layouts behalten ihre eigene Blattgröße. Unter Weitere Optionen können Sie ein Blatt stattdessen auf A4, A3, A2 oder A1 anpassen. Modellzeichnungen werden an das gewählte Papier angepasst.

Was Sie prüfen sollten, bevor Sie sich auf das PDF verlassen

  • Beschriftung. Die AutoCAD-Schriften sind auf dieser Seite nicht installiert, daher wird eine ähnliche Einlinienschrift verwendet. Die Buchstabenformen können leicht von einem AutoCAD-Plot abweichen. Chinesischer, japanischer, koreanischer, russischer und arabischer Text wird mit den Schriften Ihres eigenen Geräts gezeichnet und als scharfes Bild in das PDF eingefügt. Er sieht richtig aus, lässt sich aber nicht markieren oder durchsuchen.
  • Verknüpfte Zeichnungen (Xrefs). Verweist die Zeichnung auf andere DWG-Dateien, legen Sie diese zusammen mit der Hauptdatei ab. Fehlende Verknüpfungen werden aufgeführt und bleiben leer.
  • Nicht unterstützte Objekte. Eingebettete OLE-Objekte und Tabellen werden nicht gezeichnet, Mehrfachlinien nur näherungsweise. Die Seite weist Sie darauf hin, wenn ein Blatt solche Objekte enthält.
  • Vergleichen Sie ein wichtiges Blatt immer mit dem Original, bevor Sie es weitergeben.

Fragen

Ist es wirklich kostenlos?

Ja. Es gibt keine Anmeldung und kein Dateilimit, abgesehen von dem, was Ihr Browser verarbeiten kann.

Ist meine Zeichnung sicher?

Die Zeichnung wird auf Ihrem eigenen Computer gelesen und umgewandelt. Sie wird an keinen Server gesendet. Siehe die Datenschutzerklärung. Der Quellcode ist öffentlich, jeder kann das prüfen.

Welche DWG-Versionen funktionieren?

Wir haben Dateien von AutoCAD R14 bis zu den aktuellen Dateien im 2018-Format getestet. Sehr alte oder beschädigte Dateien lassen sich möglicherweise nicht öffnen; dann sehen Sie eine Meldung.

Brauche ich AutoCAD?

Nein. Es funktioniert in jedem modernen Browser. Siehe auch So öffnen Sie eine DWG-Datei ohne AutoCAD.

Kann es DXF-Dateien umwandeln?

Ja, die Modellzeichnung. Siehe DXF in PDF.
