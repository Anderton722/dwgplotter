DWG-Versionen erklärt

Alle paar Jahre ändert sich das DWG-Format. Jede Version hat einen Code, etwa AC1015 oder AC1032, der ganz am Anfang der Datei steht. Diese Seite listet sie auf und erklärt, was sie für das Öffnen einer Zeichnung bedeuten.

Warum die Version wichtig ist

  • Neuere Dateien öffnen sich nicht in älterer Software. Eine im 2018-Format gespeicherte Zeichnung öffnet sich weder in AutoCAD 2017 noch in Programmen, die nur bis zum 2013-Format reichen.
  • Alte Dateien öffnen sich in neuen Viewern eventuell nicht. Viele moderne Werkzeuge, auch dieses, beginnen bei R14.
  • Das Format ändert sich seltener als die Software. AutoCAD 2024 speichert immer noch im 2018-Format, eine „2024er-Datei“ ist also eine AC1032-Datei.

So finden Sie die Version einer Datei

  1. Am schnellsten: Legen Sie sie im DWG-Versionsprüfer ab. Er liest nur die ersten Bytes, und nichts wird hochgeladen.
  2. Von Hand: Öffnen Sie die Datei in einem Texteditor. Die ersten sechs Zeichen sind der Code, zum Beispiel AC1027.
  3. Bei einer DXF-Datei steht die Version hinter $ACADVER nahe am Dateianfang.

So speichern Sie eine DWG in einer älteren Version

Verwenden Sie in AutoCAD „Speichern unter“ und wählen Sie einen älteren Dateityp „AutoCAD 20xx-Zeichnung“, oder legen Sie den Standard in den Optionen unter „Öffnen und Speichern“ fest. Andere CAD-Programme haben eine ähnliche Einstellung. Ohne CAD-Software bitten Sie den Absender darum oder wandeln die Zeichnung in eine PDF um.
