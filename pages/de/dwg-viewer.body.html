Kostenloser DWG-Viewer online, ohne Upload

Öffnen Sie eine DWG-Zeichnung im Browser und sehen Sie sie durch: alle Blätter, Zoom, Layer und Messen. Ohne AutoCAD, ohne Konto, und die Datei verlässt nie Ihren Computer.

DWG-Datei öffnen Beispielzeichnung ausprobieren

So sehen Sie eine DWG online an

  1. Öffnen Sie den Viewer und legen Sie Ihre DWG-Datei auf der Seite ab, oder klicken Sie, um sie auszuwählen.
  2. Jedes Layout (Blatt) der Datei erscheint als Vorschau, dazu die Modellzeichnung.
  3. Klicken Sie auf eine Vorschau, um sie groß zu öffnen. Mit dem Mausrad oder zwei Fingern zoomen, mit Ziehen verschieben.
  4. Mit Layer blenden Sie Layer ein und aus, mit Messen prüfen Sie einen Abstand.

Was der Viewer kann

  • Alle Blätter sehen. Layouts erscheinen in ihrem eigenen Blattformat mit Schriftfeld, Ansichtsfenstern und Linienstärken, so wie sie für den Druck eingerichtet wurden.
  • Details vergrößern. Linien werden als Vektoren gezeichnet, kleine Texte und Bemaßungen bleiben also scharf.
  • Layer ein- und ausblenden. Durchsuchen Sie die Layerliste, blenden Sie Unnötiges aus oder zeigen Sie nur einen Layer.
  • Abstände messen. Klicken Sie zwei Punkte an und lesen Sie den Abstand in den Einheiten der Zeichnung ab. In einem Layout-Ansichtsfenster ist es der echte Abstand, nicht der auf dem Papier.
  • Speichern, was Sie sehen. Speichern Sie jedes Blatt als PDF, PNG oder JPG, ohne die ausgeblendeten Layer.

Warum ein Viewer im Browser

Die meisten kostenlosen DWG-Viewer müssen installiert werden oder laden Ihre Datei auf einen Server, um Bilder daraus zu machen. Dieser liest die Datei mit Code, der in Ihrem eigenen Browser läuft. So öffnet er vertrauliche und Kundenzeichnungen sicher und funktioniert auf jedem Computer, auch auf Büro-PCs, auf denen Sie nichts installieren dürfen.

Fragen

Kann ich die Zeichnung bearbeiten?

Nein. Dies ist ein Viewer und Konverter. Zum Bearbeiten einer DWG brauchen Sie CAD-Software.

Welche DWG-Dateien lassen sich öffnen?

Zeichnungen aus AutoCAD R14 bis zum aktuellen 2018-Format sowie DXF-Dateien. Sie wissen nicht, welche Version Sie haben? Nutzen Sie den DWG-Versionsprüfer.

Funktioniert es auf Mac oder Chromebook?

Ja, in Safari, Chrome, Edge und Firefox. Siehe DWG auf dem Mac und DWG auf dem Chromebook.

Gibt es eine Größenbegrenzung?

Nur den Arbeitsspeicher Ihres Computers. Zeichnungen mit mehreren Dutzend Megabyte öffnen sich auf einem normalen Laptop problemlos.
