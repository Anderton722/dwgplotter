Kostenloser DWG-Viewer online, ohne Upload

DWG-Dateien online im Browser ansehen: alle Blätter, Zoom, Layer und Messen. Ohne AutoCAD, ohne Konto, ohne Installation, und die Datei verlässt nie Ihren Computer.

DWG-Datei öffnen Beispielzeichnung ausprobieren

So öffnen Sie eine DWG-Datei online

  1. Legen Sie Ihre DWG-Datei im Feld oben auf dieser Seite ab, oder klicken Sie darauf, um sie auszuwählen. Der Viewer öffnet sich mit Ihrer Zeichnung.
  2. Jedes Layout (Blatt) der Datei erscheint als Vorschau, dazu die Modellzeichnung.
  3. Klicken Sie auf eine Vorschau, um sie groß zu öffnen. Mit dem Mausrad oder zwei Fingern zoomen, mit Ziehen verschieben.
  4. Mit Layer blenden Sie Layer ein und aus, mit Messen prüfen Sie einen Abstand.

Das ist alles. Es gibt keinen Upload und kein Warten auf einen Server, die Zeichnung erscheint, sobald Ihr Browser sie gelesen hat.

Was der Viewer kann

  • Alle Blätter sehen. Layouts erscheinen in ihrem eigenen Blattformat mit Schriftfeld, Ansichtsfenstern und Linienstärken, so wie sie für den Druck eingerichtet wurden.
  • Details vergrößern. Linien werden als Vektoren gezeichnet, kleine Texte und Bemaßungen bleiben also scharf.
  • Layer ein- und ausblenden. Durchsuchen Sie die Layerliste, blenden Sie Unnötiges aus oder zeigen Sie nur einen Layer.
  • Abstände messen. Klicken Sie zwei Punkte an und lesen Sie den Abstand in den Einheiten der Zeichnung ab. In einem Layout-Ansichtsfenster ist es der echte Abstand, nicht der auf dem Papier.
  • Speichern, was Sie sehen. Speichern Sie jedes Blatt als PDF, PNG oder JPG, ohne die ausgeblendeten Layer. Siehe DWG in PDF.
  • Verknüpfte Zeichnungen öffnen. Legen Sie die Hauptzeichnung und ihre Xrefs zusammen ab, dann erscheinen sie an ihrer Stelle. Siehe DWG mit Xrefs.

Wenn Sie eine Zeichnung nur ansehen, ein Maß prüfen oder sie drucken möchten, reicht ein Viewer. CAD-Software brauchen Sie nur, um die Zeichnung zu ändern.

Warum ein Viewer im Browser

Die meisten kostenlosen DWG-Viewer müssen installiert werden oder laden Ihre Datei auf einen Server, um Bilder daraus zu machen. Dieser liest die Datei mit Code, der in Ihrem eigenen Browser läuft. So öffnet er vertrauliche und Kundenzeichnungen sicher und funktioniert auf jedem Computer, auch auf Büro-PCs, auf denen Sie nichts installieren dürfen. Der Quellcode ist öffentlich, jeder kann prüfen, dass nichts gesendet wird.

DWG aus E-Mail, Teams oder der Cloud öffnen

Speichern Sie zuerst den Anhang oder laden Sie die Datei aus OneDrive, Google Drive, Dropbox oder SharePoint herunter, und legen Sie sie dann oben ab. Kam die Datei als ZIP (eTransmit-Paket), entpacken Sie sie und legen Sie die DWG-Dateien zusammen ab, damit verknüpfte Zeichnungen (Xrefs) an ihrer Stelle erscheinen. Öffnet sie sich trotzdem nicht, siehe DWG-Datei lässt sich nicht öffnen.

Fragen

Ist dieser DWG-Viewer wirklich kostenlos?

Ja. Keine Testversion, kein Wasserzeichen und keine Begrenzung der Dateien. Es ist kostenlose Open-Source-Software.

Muss ich mich anmelden?

Nein. Kein Konto, keine E-Mail-Adresse. Seite öffnen, Datei ablegen, und die Zeichnung erscheint.

Wird meine Zeichnung hochgeladen?

Nein. Die Datei wird in Ihrem Browser gelesen und an keinen Server gesendet. Siehe Datenschutz.

Kann ich die Zeichnung bearbeiten?

Nein. Dies ist ein Viewer und Konverter, kein Online-DWG-Editor. Sie können ansehen, messen, Layer schalten und als PDF oder Bild speichern. Zum Bearbeiten einer DWG brauchen Sie CAD-Software.

Kann ich eine DWG-Datei ohne AutoCAD öffnen?

Ja. Dieser Viewer braucht weder AutoCAD noch ein anderes CAD-Programm. Weitere Wege unter DWG ohne AutoCAD öffnen.

Welche DWG-Dateien lassen sich öffnen?

Zeichnungen aus AutoCAD R14 bis zum aktuellen 2018-Format sowie DXF-Dateien. Sie wissen nicht, welche Version Sie haben? Nutzen Sie den DWG-Versionsprüfer.

Funktioniert es auf Mac oder Chromebook?

Ja, in Safari, Chrome, Edge und Firefox. Siehe DWG auf dem Mac und DWG auf dem Chromebook.

Kann ich eine DWG auf dem Handy oder Tablet ansehen?

Ja, im Browser des Geräts. Kleine Blätter sind gut lesbar, für große A1- oder A0-Blätter ist ein Computerbildschirm angenehmer.

Gibt es eine Größenbegrenzung?

Nur den Arbeitsspeicher Ihres Computers. Zeichnungen mit mehreren Dutzend Megabyte öffnen sich auf einem normalen Laptop problemlos.
