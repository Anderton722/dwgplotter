DXF in PDF, kostenlos und im Browser

Legen Sie eine DXF-Zeichnung ab und speichern Sie sie als PDF. Sie wird auf Ihrem eigenen Computer gelesen und nie hochgeladen.

Konverter öffnen

So wandeln Sie eine DXF-Datei in PDF um

  1. Öffnen Sie den Konverter und legen Sie Ihre DXF-Datei auf der Seite ab.
  2. Haken Sie die gewünschten Zeichnungen an und wählen Sie Schwarzweiß oder Farbe.
  3. Klicken Sie auf PDF herunterladen.

Was unterstützt wird

DXF ist ein Austauschformat, das viele CAD-Programme speichern können. Der Konverter liest die gängigen Objekte: Linien, Polylinien, Bögen, Kreise, Ellipsen, Text, Blöcke, Bemaßungen, Führungslinien und gefüllte Flächen (Schraffuren) sowie Layer, Linientypen und Linienstärken.

Grenzen, die Sie kennen sollten

  • Nur die Modellzeichnung. Blatt-Layouts werden aus DXF-Dateien nicht gelesen, Sie erhalten also die Zeichnung im Modell. Für Layouts verwenden Sie die ursprüngliche DWG-Datei.
  • Einige Objekte werden übersprungen, etwa Punkte und Blockattributtext.
  • Text. Es wird eine ähnliche Einlinienschrift verwendet, daher können die Buchstabenformen leicht vom Plot des CAD-Programms abweichen.
  • Vergleichen Sie eine wichtige Zeichnung mit dem Original, bevor Sie sie weitergeben.

Fragen

Wird meine Zeichnung hochgeladen?

Nein. Die Datei wird in Ihrem Browser gelesen. Siehe die Datenschutzerklärung.

Was ist der Unterschied zwischen DWG und DXF?

DWG ist das eigene Format von AutoCAD. DXF ist ein textbasiertes Austauschformat, das auch andere Programme lesen und schreiben. DWG-Dateien enthalten die Blatt-Layouts, deshalb empfehlen wir DWG, wenn Sie es haben.
