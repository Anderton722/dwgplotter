Alle Layouts in eine PDF drucken

Eine DWG enthält oft einen ganzen Plansatz: Grundrisse, Ansichten, Schnitte und Details, jeweils auf einem eigenen Layout-Register. Speichern Sie alle in einem Schritt als mehrseitige PDF, kostenlos und ohne AutoCAD.

DWG öffnen

So plotten Sie alle Layouts in eine PDF

  1. Öffnen Sie den Konverter und legen Sie die DWG-Datei ab.
  2. Alle Layouts der Datei werden aufgelistet, in der Reihenfolge der Register in der Zeichnung. Klicken Sie auf Alle auswählen oder wählen Sie nur die benötigten Blätter.
  3. Lassen Sie Zusammen gewählt, um eine einzige PDF zu erhalten, oder wählen Sie Einzeln für eine PDF pro Blatt in einer ZIP-Datei.
  4. Klicken Sie auf PDF herunterladen.

Jedes Blatt in seinem Format

Jede Seite der PDF behält das Papierformat ihres Layouts. Ein A1-Übersichtsplan bleibt A1 und ein A3-Detailblatt bleibt A3, so wird der Plansatz im richtigen Maßstab gedruckt. Sollen alle Seiten gleich groß sein, wählen Sie unter Weitere Optionen A4, A3, A2 oder A1, und jedes Blatt wird darauf eingepasst.

Warum nicht jedes Register einzeln drucken?

Jedes Layout einzeln zu drucken und die PDFs danach zusammenzufügen kostet Zeit und braucht ein zweites Programm. Hier werden die Blätter in einem Schritt zusammengeführt, in der Reihenfolge der Register.

Fragen

Gibt es eine Begrenzung der Blattanzahl?

Nein. Große Plansätze mit Dutzenden Layouts funktionieren. Sie dauern nur etwas länger.

Kann ich auch die Modellzeichnung aufnehmen?

Ja. Das Modell steht neben den Layouts in der Liste. Enthält es mehrere Zeichnungen, listet Smart-Plot jede einzeln.

Werden verknüpfte Zeichnungen (Xrefs) einbezogen?

Ja, wenn Sie die verknüpften Dateien zusammen mit der Hauptzeichnung ablegen. Siehe DWG in PDF mit Xrefs.
