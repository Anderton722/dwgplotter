So öffnen Sie eine DWG-Datei ohne AutoCAD

DWG ist das Zeichnungsformat von AutoCAD. Wenn Ihnen jemand eine solche Datei schickt und Sie die Software nicht haben, gibt es trotzdem Möglichkeiten.

DWG im Browser öffnen

Möglichkeit 1: Im Browser öffnen

Die Seite DWG Plotter liest die Datei auf Ihrem eigenen Computer, zeigt jedes Blatt als Vorschau und lässt Sie die Zeichnung als PDF speichern. In der großen Vorschau können Sie zoomen, Layer ein- und ausschalten und Abstände messen. Es wird nichts hochgeladen – eine sinnvolle Wahl für Kunden- oder vertrauliche Zeichnungen.

Möglichkeit 2: Ein PDF anfordern

Wer Ihnen die Zeichnung geschickt hat, kann meist in einer Minute ein PDF exportieren. Das ist der beste Weg, wenn Sie das Blatt genau so brauchen, wie es geplottet wurde, denn dort lassen sich die richtigen Schriften und Ploteinstellungen verwenden. Ist das nicht möglich, ist der Konverter oben die schnellste Alternative.

Möglichkeit 3: Ein kostenloser Viewer von Autodesk

Autodesk, der Hersteller von AutoCAD, bietet kostenlose Möglichkeiten zum Ansehen von DWG-Dateien, etwa einen Desktop-Viewer für Windows und einen Online-Viewer. Sie erfordern unter Umständen eine Installation oder ein Autodesk-Konto, und Online-Viewer laden Ihre Datei hoch – prüfen Sie daher deren Bedingungen, wenn die Zeichnung vertraulich ist.

Was ohne AutoCAD möglich ist und was nicht

  • Möglich: die Zeichnung lesen, hineinzoomen, Layer prüfen, messen und ein PDF drucken oder speichern.
  • Nicht möglich: die Zeichnung bearbeiten. Dafür brauchen Sie CAD-Software.

Tipps

  • Fehlen Teile? Die Zeichnung verweist möglicherweise auf andere DWG-Dateien (Xrefs). Bitten Sie den Absender darum und legen Sie sie zusammen mit der Hauptdatei ab.
  • Leere Seite? Manche Zeichnungen haben keine Layouts, und alles liegt im Modell. Der Smart-Plot des Konverters findet in diesem Fall die eigentlichen Zeichnungen.
  • Alte Datei? Zeichnungen ab R14 lassen sich öffnen. Dateien in anderen Formaten wie DXF behandelt DXF in PDF.
