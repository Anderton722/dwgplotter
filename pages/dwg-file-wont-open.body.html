DWG file won't open? Causes and fixes

Most DWG files that fail to open have one of a handful of problems. Work down this list to find yours.

Try opening it here

1. The download is incomplete or damaged

Email systems and messaging apps sometimes cut off or block DWG attachments. Check the file size: a drawing of a few kilobytes, or 0 bytes, is broken. Ask the sender to send it again, ideally zipped or through a file-sharing link.

2. It is still zipped

Drawings are often sent as a zip file (an eTransmit package), sometimes with a name ending in .dwg.zip. Unzip it first, then open the DWG files inside.

3. The version is too old, or too new for your software

Every few years AutoCAD changes the DWG format. Older software cannot open files saved in a newer format, and very old files (R13 and earlier) are not supported by many modern viewers. Use the DWG version checker to see which format your file is in. Our viewer opens R14 to the current 2018 format. If you have older software, ask the sender to save the drawing in an older version.

4. It is not really a DWG

A few other programs use the .dwg ending for unrelated files. The version checker will tell you if the file is not an AutoCAD drawing.

5. It opens but looks empty or incomplete

  • Missing xrefs. The drawing links to other DWG files that were not sent. See DWG with xrefs.
  • Everything is in the model. Some drawings have empty layouts. Look at the model drawing instead. Smart plot finds the separate drawings in it.
  • Objects from specialist software. Drawings from civil, MEP and other industry versions of AutoCAD can contain custom objects that other programs cannot draw. Ask the sender to export a PDF, or to explode those objects.
  • Frozen or switched-off layers. Parts of the drawing may sit on layers that are switched off. Check the layer list in the large preview.

6. It is password-protected

Some older versions of AutoCAD could save drawings with a password. These cannot be opened without the original software and the password.

7. It is very large

A drawing of hundreds of megabytes may exceed the memory of a browser or a small laptop. Close other tabs and use a desktop computer, or ask for the sheets you need as PDFs.
