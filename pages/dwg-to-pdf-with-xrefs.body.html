DWG to PDF with xrefs included

Many drawings show other DWG files inside them, such as a site plan, a structural grid or a title block. These are xrefs (external references). Drop them in with the main drawing and they print in place.

Open your drawings

How to convert a DWG with xrefs

  1. Put the main drawing and its linked DWG files in one folder, or download them all from the sender.
  2. Open the converter and drop all of the files at once. The main drawing is found automatically.
  3. The page lists every linked file and marks any that are missing. You can add missing files with Add files, or choose Continue without them.
  4. Tick the sheets you want and click Download PDF.

Why parts of a drawing are missing

If a PDF shows a title block with an empty drawing area, or a plan without its background, the drawing almost certainly uses xrefs that were not sent with it. A DWG only stores the name and path of each xref, not its contents. Ask the sender for the linked files, or for an eTransmit zip, which bundles them.

Tips

  • Received a zip? Unzip it first, then drop in all of the DWG files inside it.
  • Nested xrefs (an xref inside an xref) also work, as long as all of the files are dropped in.
  • File names matter. Xrefs are matched by file name, so do not rename the linked files.
  • Images, PDFs and other non-DWG files attached to the drawing are not drawn.

Questions

Are my files uploaded?

No. All of the drawings are read in your own browser. See the privacy policy.

Can I print without the missing xrefs?

Yes. Choose Continue without them and those parts are left blank.
