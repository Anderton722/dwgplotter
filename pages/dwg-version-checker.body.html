DWG version checker

Find out which version of AutoCAD a DWG or DXF file was saved in. Drop the file below. Only the first few bytes are read, and nothing is uploaded.

What the result means

The version code, such as AC1027, decides which software can open a drawing. Newer codes do not open in older programs. The full list is in DWG versions explained.

  • AC1032 (2018 format) is used by every AutoCAD release from 2018 to today.
  • AC1027 (2013 format) is used by releases 2013 to 2017.
  • AC1024 (2010 format) is used by releases 2010 to 2012.

Questions

Is my file uploaded?

No. The checker reads the start of the file in your browser and nothing is sent anywhere.

Which AutoCAD version do I need to open it?

Any release from the one named in the result onwards. For example, an AC1027 file opens in AutoCAD 2013 and later. To look at it without AutoCAD, use the free DWG viewer.
