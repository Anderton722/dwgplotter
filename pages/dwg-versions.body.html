DWG versions explained

Every few years the DWG format changes. Each version has a code, such as AC1015 or AC1032, written at the very start of the file. This page lists them and explains what they mean for opening a drawing.

Why the version matters

  • Newer files do not open in older software. A drawing saved in the 2018 format will not open in AutoCAD 2017 or in other programs that stop at the 2013 format.
  • Old files may not open in new viewers. Many modern tools, including this one, start at R14.
  • The format changes less often than the software. AutoCAD 2024 still saves in the 2018 format, so "a 2024 file" is an AC1032 file.

How to find a file's version

  1. The quick way: drop it into the DWG version checker. It reads only the first few bytes and nothing is uploaded.
  2. By hand: open the file in a plain text editor. The first six characters are the code, for example AC1027.
  3. For a DXF file, the version is stored after $ACADVER near the top of the file.

How to save a DWG in an older version

In AutoCAD, use Save As and choose an older "AutoCAD 20xx Drawing" type, or set the default in the Open and Save options. Other CAD programs have a similar setting. If you do not have CAD software, ask the sender to do it, or convert the drawing to PDF instead.
