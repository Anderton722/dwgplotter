How to view a DWG file online

  1. Drop your DWG file into the box at the top of this page, or click it to choose the file. The viewer opens with your drawing.
  2. Every layout (sheet) in the file appears as a preview, plus the model drawing.
  3. Click a preview to open it large. Scroll or pinch to zoom, and drag to move around.
  4. Use Layers to switch layers on and off, and Measure to check a distance.

That is all. There is no upload step and no waiting for a server to convert the file, so the drawing appears as soon as your browser has read it.

What you can do in the viewer

  • See every sheet. Layouts show at their own sheet size with title blocks, viewports and lineweights, the way they were set up for printing.
  • Zoom in on detail. Lines are drawn as vectors, so small text and dimensions stay sharp however far you zoom.
  • Switch layers on and off. Search the layer list, hide what you do not need, or show only one layer.
  • Measure distances. Click two points to read the distance in the drawing's units. Inside a layout viewport it gives the real distance, not the paper distance.
  • Save what you see. Save any sheet as a PDF, PNG or JPG, with the layers you switched off left out. See DWG to PDF and DWG to PNG.
  • Open linked drawings. Drop the main drawing and its xrefs in together and they show in place. See DWG with xrefs.

Why a browser viewer

Most free DWG viewers either need an installation or upload your file to a server to turn it into pictures. This one reads the file with code that runs in your own browser, so it opens confidential and client drawings safely and works on any computer, including office PCs where you cannot install software. The code is open source, so anyone can check that nothing is sent.

Who uses an online DWG viewer

  • Builders and site teams checking a plan or detail an architect has emailed.
  • Clients and homeowners looking through the drawings for their project.
  • Engineers and estimators measuring quantities from a drawing they cannot edit.
  • Fabricators checking a DWG or DXF before laser cutting or CNC work.
  • Students opening course drawings on a laptop without CAD software.

Open a DWG from email, Teams or the cloud

Save the attachment or download the file from OneDrive, Google Drive, Dropbox or SharePoint first, then drop it in above. If the file came as a zip (an eTransmit package), extract it and drop the DWG files in together so linked drawings (xrefs) show in place. If it still will not open, see DWG file won't open.

Tips for large drawings

  • Close other heavy browser tabs before opening a drawing of 50 MB or more.
  • Open one sheet large at a time. The previews are kept small so a big set stays quick.
  • Switch off busy layers such as hatching or furniture to find what you need faster.

Questions

Is this DWG viewer really free?

Yes. There is no trial, no watermark and no limit on the number of files. It is free, open-source software.

Do I need to sign up or log in?

No. There is no account, no email address and no trial. Open the page, drop the file in and the drawing appears.

Is my drawing uploaded?

No. The file is read inside your browser and is not sent to any server. See the privacy policy.

Can I edit the drawing?

No. This is a viewer and converter, not an online DWG editor. You can view, measure, switch layers and save as PDF or an image. Editing a DWG needs CAD software.

Can I open a DWG file without AutoCAD?

Yes. This viewer needs no AutoCAD and no other CAD program. See how to open a DWG without AutoCAD for the other options.

Which DWG files open?

Drawings saved from AutoCAD R14 up to the current 2018 format, plus DXF files. Not sure which version you have? Use the DWG version checker.

Does it work on a Mac or Chromebook?

Yes. It runs in Safari, Chrome, Edge and Firefox. See DWG on a Mac and DWG on a Chromebook.

Can I view a DWG on my phone or tablet?

Yes, in the phone's browser. Small sheets read fine; for large A1 or A0 sheets a computer screen is more comfortable.

Can I print a DWG from the viewer?

Yes. Save the sheets as a PDF, then print the PDF at the size you need. See every layout into one PDF.

Is there a file size limit?

Only your computer's memory. Drawings of several tens of megabytes open fine on a normal laptop.
