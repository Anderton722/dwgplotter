  1. Open the converter and drop your DXF file onto the page.
  2. Tick the drawings you want, and choose black and white or colour.
  3. Click Download PDF.

What is supported

DXF is an exchange format that many CAD programs can save. The converter reads the common objects: lines, polylines, arcs, circles, ellipses, text, blocks, dimensions, leaders and filled areas (hatches), along with layers, linetypes and lineweights.

Limits to know about

  • Model drawing only. Sheet layouts are not read from DXF files, so you get the drawing in the model. For layouts, use the original DWG.
  • Some objects are skipped, such as points and block attribute text.
  • Text. It uses a similar single-stroke font, so letter shapes can differ slightly from the CAD program's plot.
  • Check an important drawing against the original before sending it out.

Questions

Is my drawing uploaded?

No. The file is read in your browser. See the privacy policy.

What is the difference between DWG and DXF?

DWG is AutoCAD's own format. DXF is a text-based exchange format that other programs also read and write. DWG files keep sheet layouts, which is why we recommend DWG when you have it.
