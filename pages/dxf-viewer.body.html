Free online DXF viewer, right in your browser

View a DXF drawing without installing anything. Zoom in, switch layers on and off, measure, and save it as a PDF or image. The file is read on your computer and never uploaded.

Open a DXF file

How to view a DXF file

  1. Open the viewer and drop the DXF file onto the page.
  2. The drawing appears as a preview. If the model holds several separate drawings, Smart plot shows each one on its own.
  3. Click a preview to open it large, then zoom, pan, hide layers or measure.

DXF files from any program

DXF is the exchange format that most CAD, CAM and design programs can save, from architecture software to laser-cutter and CNC tools. The viewer reads the usual objects: lines, polylines, arcs, circles, ellipses, splines, text, blocks, dimensions, leaders and hatches, along with layers, colours, linetypes and lineweights.

Good to know

  • Model drawing only. Sheet layouts are not read from DXF files. If you have the original DWG, open that to see the sheets.
  • Text uses a similar single-stroke font, so letter shapes can differ slightly from the CAD program.
  • Points and block attribute text are not drawn.

Questions

Is my DXF uploaded?

No. It is read inside your browser. See the privacy policy.

Can I convert the DXF to PDF?

Yes. Tick the drawings you want and click Download PDF. See DXF to PDF for the details.

What is the difference between DXF and DWG?

DWG is AutoCAD's own compact format. DXF is a text-based exchange format that other programs can read and write. See what is a DWG file.
