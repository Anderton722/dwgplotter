AC1015 : le format DWG d'AutoCAD 2000

AC1015 est le code de version du format DWG d'AutoCAD 2000. Un dessin qui commence par AC1015 a été enregistré par AutoCAD 2000, 2000i et 2002, ou par un autre logiciel de CAO réglé sur ce format. AutoCAD 2000, la première version à l'enregistrer, a introduit les présentations multiples et les épaisseurs de ligne, dont le traçage dépend encore.

Quels logiciels ouvrent un fichier AC1015

Toutes les versions d'AutoCAD et d'AutoCAD LT depuis la 2000 l'ouvrent, ainsi que la plupart des autres logiciels de CAO qui lisent le DWG. AutoCAD R14 et les versions antérieures ne peuvent pas l'ouvrir et affichent une erreur.

Sans AutoCAD, déposez le fichier dans la visionneuse DWG gratuite : vous voyez chaque présentation, vous pouvez zoomer, mesurer et l'enregistrer en PDF. Le fichier est lu sur votre ordinateur et n'est jamais envoyé.

Pourquoi les logiciels demandent AC1015

Presque tous les logiciels qui importent du DWG ou du DXF, y compris les anciens logiciels de CN, de FAO et de SIG, lisent le format 2000. C'est pourquoi les options d'export et les demandes de fichiers indiquent souvent « DWG AutoCAD 2000 ». Seules la Release 14 et les versions antérieures ne peuvent pas l'ouvrir.

Enregistrer un dessin en AC1015

Dans AutoCAD 2000 ou ultérieur, choisissez Enregistrer sous et le type de fichier « Dessin AutoCAD 2000/LT2000 (*.dwg) ». Pour en faire le format par défaut, modifiez-le dans Options, Ouvrir et enregistrer. Enregistrer dans un format plus ancien peut simplifier des objets que ce format ne gère pas : gardez aussi l'original.

Questions

Quelle version d'AutoCAD correspond à AC1015 ?

C'est le format DWG d'AutoCAD 2000, utilisé par AutoCAD 2000, 2000i et 2002.

AutoCAD R14 peut-il ouvrir un fichier AC1015 ?

Non. La Release 14 ne lit que jusqu'à AC1014. Affichez le dessin dans un navigateur ou convertissez-le en PDF.

Comment savoir si mon fichier est en AC1015 ?

Déposez-le dans le vérificateur de version DWG, ou ouvrez-le dans un éditeur de texte : les six premiers caractères sont le code de version.

Les fichiers DXF utilisent-ils le même code AC1015 ?

Oui. Un DXF enregistre le même code après $ACADVER, près du début : un DXF marqué AC1015 est au format 2000.
