AC1018 : le format DWG d'AutoCAD 2004

AC1018 est le code de version du format DWG d'AutoCAD 2004. Un dessin qui commence par AC1018 a été enregistré par AutoCAD 2004 à 2006, ou par un autre logiciel de CAO réglé sur ce format. AutoCAD 2004, la première version à l'enregistrer, a introduit les couleurs vraies et les carnets de couleurs.

Quels logiciels ouvrent un fichier AC1018

Toutes les versions d'AutoCAD et d'AutoCAD LT depuis la 2004 l'ouvrent, ainsi que la plupart des autres logiciels de CAO qui lisent le DWG. AutoCAD 2002 et les versions antérieures ne peuvent pas l'ouvrir et affichent une erreur.

Sans AutoCAD, déposez le fichier dans la visionneuse DWG gratuite : vous voyez chaque présentation, vous pouvez zoomer, mesurer et l'enregistrer en PDF. Le fichier est lu sur votre ordinateur et n'est jamais envoyé.

L'ouvrir dans un AutoCAD plus ancien

Demandez à l'expéditeur d'enregistrer une copie dans un format plus ancien : Enregistrer sous, puis le type « Dessin AutoCAD 20xx » adapté à votre version, par exemple « Dessin AutoCAD 2000/LT2000 (*.dwg) ». Si vous devez seulement consulter ou imprimer le dessin, le convertir en PDF est plus rapide.

Enregistrer un dessin en AC1018

Dans AutoCAD 2004 ou ultérieur, choisissez Enregistrer sous et le type de fichier « Dessin AutoCAD 2004/LT2004 (*.dwg) ». Pour en faire le format par défaut, modifiez-le dans Options, Ouvrir et enregistrer. Enregistrer dans un format plus ancien peut simplifier des objets que ce format ne gère pas : gardez aussi l'original.

Questions

Quelle version d'AutoCAD correspond à AC1018 ?

C'est le format DWG d'AutoCAD 2004, utilisé par AutoCAD 2004 à 2006.

AutoCAD 2002 peut-il ouvrir un fichier AC1018 ?

Non. AutoCAD 2002 ne lit que jusqu'à AC1015. Enregistrez le dessin en « Dessin AutoCAD 2000/LT2000 (*.dwg) » ou affichez-le dans un navigateur.

Comment savoir si mon fichier est en AC1018 ?

Déposez-le dans le vérificateur de version DWG, ou ouvrez-le dans un éditeur de texte : les six premiers caractères sont le code de version.

Les fichiers DXF utilisent-ils le même code AC1018 ?

Oui. Un DXF enregistre le même code après $ACADVER, près du début : un DXF marqué AC1018 est au format 2004.
