AC1024 : le format DWG d'AutoCAD 2010

AC1024 est le code de version du format DWG d'AutoCAD 2010. Un dessin qui commence par AC1024 a été enregistré par AutoCAD 2010 à 2012, ou par un autre logiciel de CAO réglé sur ce format. AutoCAD 2010, la première version à l'enregistrer, a aussi introduit les contraintes paramétriques et la modélisation de maillages.

Quels logiciels ouvrent un fichier AC1024

Toutes les versions d'AutoCAD et d'AutoCAD LT depuis la 2010 l'ouvrent, ainsi que la plupart des autres logiciels de CAO qui lisent le DWG. AutoCAD 2009 et les versions antérieures ne peuvent pas l'ouvrir et affichent une erreur.

Sans AutoCAD, déposez le fichier dans la visionneuse DWG gratuite : vous voyez chaque présentation, vous pouvez zoomer, mesurer et l'enregistrer en PDF. Le fichier est lu sur votre ordinateur et n'est jamais envoyé.

L'ouvrir dans un AutoCAD plus ancien

Demandez à l'expéditeur d'enregistrer une copie dans un format plus ancien : Enregistrer sous, puis le type « Dessin AutoCAD 20xx » adapté à votre version, par exemple « Dessin AutoCAD 2007/LT2007 (*.dwg) ». Si vous devez seulement consulter ou imprimer le dessin, le convertir en PDF est plus rapide.

Enregistrer un dessin en AC1024

Dans AutoCAD 2010 ou ultérieur, choisissez Enregistrer sous et le type de fichier « Dessin AutoCAD 2010/LT2010 (*.dwg) ». Pour en faire le format par défaut, modifiez-le dans Options, Ouvrir et enregistrer. Enregistrer dans un format plus ancien peut simplifier des objets que ce format ne gère pas : gardez aussi l'original.

Questions

Quelle version d'AutoCAD correspond à AC1024 ?

C'est le format DWG d'AutoCAD 2010, utilisé par AutoCAD 2010 à 2012.

AutoCAD 2009 peut-il ouvrir un fichier AC1024 ?

Non. AutoCAD 2009 ne lit que jusqu'à AC1021. Enregistrez le dessin en « Dessin AutoCAD 2007/LT2007 (*.dwg) » ou affichez-le dans un navigateur.

Comment savoir si mon fichier est en AC1024 ?

Déposez-le dans le vérificateur de version DWG, ou ouvrez-le dans un éditeur de texte : les six premiers caractères sont le code de version.

Les fichiers DXF utilisent-ils le même code AC1024 ?

Oui. Un DXF enregistre le même code après $ACADVER, près du début : un DXF marqué AC1024 est au format 2010.
