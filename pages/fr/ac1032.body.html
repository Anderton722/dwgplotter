AC1032 : le format DWG d'AutoCAD 2018

AC1032 est le code de version du format DWG d'AutoCAD 2018. Un dessin qui commence par AC1032 a été enregistré par AutoCAD 2018 jusqu'à la version actuelle, ou par un autre logiciel de CAO réglé sur ce format. C'est le format DWG le plus durable à ce jour : toutes les versions depuis 2018 l'utilisent encore, donc la plupart des dessins actuels sont en AC1032.

Quels logiciels ouvrent un fichier AC1032

Toutes les versions d'AutoCAD et d'AutoCAD LT depuis la 2018 l'ouvrent, ainsi que la plupart des autres logiciels de CAO qui lisent le DWG. AutoCAD 2017 et les versions antérieures ne peuvent pas l'ouvrir et affichent une erreur.

Sans AutoCAD, déposez le fichier dans la visionneuse DWG gratuite : vous voyez chaque présentation, vous pouvez zoomer, mesurer et l'enregistrer en PDF. Le fichier est lu sur votre ordinateur et n'est jamais envoyé.

L'ouvrir dans un AutoCAD plus ancien

Demandez à l'expéditeur d'enregistrer une copie dans un format plus ancien : Enregistrer sous, puis le type « Dessin AutoCAD 20xx » adapté à votre version, par exemple « Dessin AutoCAD 2013/LT2013 (*.dwg) ». Si vous devez seulement consulter ou imprimer le dessin, le convertir en PDF est plus rapide.

Enregistrer un dessin en AC1032

Dans AutoCAD 2018 ou ultérieur, choisissez Enregistrer sous et le type de fichier « Dessin AutoCAD 2018 (*.dwg) ». Pour en faire le format par défaut, modifiez-le dans Options, Ouvrir et enregistrer. Enregistrer dans un format plus ancien peut simplifier des objets que ce format ne gère pas : gardez aussi l'original. C'est déjà le format par défaut de toutes les versions actuelles.

Questions

Quelle version d'AutoCAD correspond à AC1032 ?

C'est le format DWG d'AutoCAD 2018, utilisé par AutoCAD 2018 jusqu'à la version actuelle.

AutoCAD 2017 peut-il ouvrir un fichier AC1032 ?

Non. AutoCAD 2017 ne lit que jusqu'à AC1027. Enregistrez le dessin en « Dessin AutoCAD 2013/LT2013 (*.dwg) » ou affichez-le dans un navigateur.

Comment savoir si mon fichier est en AC1032 ?

Déposez-le dans le vérificateur de version DWG, ou ouvrez-le dans un éditeur de texte : les six premiers caractères sont le code de version.

Les fichiers DXF utilisent-ils le même code AC1032 ?

Oui. Un DXF enregistre le même code après $ACADVER, près du début : un DXF marqué AC1032 est au format 2018.
