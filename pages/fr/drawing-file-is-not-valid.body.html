« Le fichier dessin n'est pas valide » : causes et solutions

AutoCAD et d'autres logiciels de CAO affichent « Le fichier dessin n'est pas valide » (« Drawing file is not valid ») quand ils ne peuvent pas lire un DWG. Le plus souvent, le fichier est abîmé, incomplet ou n'est pas vraiment un DWG. Voici comment savoir lequel et récupérer le dessin.

Essayer d'ouvrir le fichier ici

D'abord, vérifiez ce qu'est le fichier

Déposez-le dans le vérificateur de version DWG. Il ne lit que les premiers octets, dans votre navigateur.

  • Il affiche un code de version comme AC1032 ou AC1027 : le fichier est un vrai DWG et le problème est plus loin à l'intérieur. Passez aux solutions ci-dessous.
  • Il indique que ce n'est pas un dessin : le fichier a été tronqué, renommé, compressé, ou c'est un autre type de fichier. Voir « Le fichier n'est pas vraiment un DWG ».

Causes courantes

Pourquoi un DWG affiche-t-il « le fichier dessin n'est pas valide » ?

Les causes les plus fréquentes sont un téléchargement ou une pièce jointe incomplète, un fichier enregistré pendant un plantage ou une coupure réseau, un fichier renommé en .dwg qui est en réalité autre chose, et un fichier enregistré par un logiciel qui écrit mal le format DWG.

Est-ce parce que le fichier est trop récent ?

En général non. Un fichier d'une version plus récente donne normalement un autre message, sur une version incompatible. Voir DWG créé par une version incompatible.

Solutions, de la plus rapide à la plus longue

1. Obtenez une nouvelle copie

Regardez la taille du fichier. Un dessin de 0 octet ou de quelques kilo-octets est cassé. Demandez à l'expéditeur de le renvoyer, compressé ou par un lien de partage, car les messageries tronquent ou bloquent parfois les pièces jointes DWG.

2. Ouvrez-le avec un autre logiciel

Chaque logiciel lit les fichiers abîmés différemment. Essayez la visionneuse DWG gratuite : si le dessin s'ouvre, enregistrez-le tout de suite en PDF.

3. Utilisez le fichier de sauvegarde

AutoCAD conserve l'enregistrement précédent dans un fichier .bak du même dossier. Copiez-le, renommez la copie de .bak en .dwg et ouvrez-la. Vous ne perdez que les modifications depuis le dernier enregistrement.

4. Cherchez un fichier d'enregistrement automatique

Ces fichiers se terminent par .sv$ et se trouvent dans le dossier temporaire indiqué dans les options du logiciel. Copiez-en un, renommez-le en .dwg et ouvrez-le.

5. Lancez Récupérer dans AutoCAD

Si vous avez AutoCAD ou un logiciel de CAO similaire, utilisez la commande RECUPERER (RECOVER) au lieu d'une ouverture normale. Elle répare ce qu'elle peut et indique ce qu'elle a corrigé. Lancez ensuite AUDIT.

6. Insérez-le dans un nouveau dessin

Si Récupérer échoue, créez un nouveau dessin et insérez le fichier abîmé comme bloc ou comme xréf. Cela permet parfois de retrouver la géométrie quand l'en-tête du fichier est abîmé.

Le fichier n'est pas vraiment un DWG

  • Il est compressé. Un nom comme dessin.dwg.zip, ou un fichier qui est en fait un zip, doit d'abord être décompressé.
  • C'est un autre .dwg. Quelques logiciels sans rapport utilisent l'extension .dwg.
  • C'est un DXF ou un PDF renommé. Rendez-lui son extension et ouvrez-le comme tel.
