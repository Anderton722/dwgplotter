Le fichier DWG ne s'ouvre pas ? Causes et solutions

La plupart des fichiers DWG qui refusent de s'ouvrir ont l'un de quelques problèmes. Parcourez cette liste pour trouver le vôtre.

Essayer de l'ouvrir ici

1. Le téléchargement est incomplet ou abîmé

Les messageries coupent ou bloquent parfois les pièces jointes DWG. Vérifiez la taille du fichier : un dessin de quelques kilo-octets, ou de 0 octet, est cassé. Demandez un nouvel envoi, de préférence zippé ou par lien de partage.

2. Il est encore zippé

Les dessins sont souvent envoyés en zip (un paquet eTransmit), parfois avec un nom finissant par .dwg.zip. Décompressez-le d'abord, puis ouvrez les fichiers DWG qu'il contient.

3. La version est trop ancienne, ou trop récente pour votre logiciel

Tous les quelques ans, AutoCAD modifie le format DWG. Les anciens logiciels n'ouvrent pas les fichiers enregistrés dans un format plus récent, et beaucoup de visionneuses modernes ne prennent pas en charge les très vieux fichiers (R13 et antérieurs). Utilisez le vérificateur de version DWG pour connaître le format de votre fichier. Notre visionneuse ouvre de R14 au format actuel de 2018. Si votre logiciel est ancien, demandez à l'expéditeur d'enregistrer le dessin dans une version antérieure.

4. Ce n'est pas vraiment un DWG

Quelques autres logiciels utilisent l'extension .dwg pour des fichiers sans rapport. Le vérificateur de version vous dira si le fichier n'est pas un dessin AutoCAD.

5. Il s'ouvre mais semble vide ou incomplet

  • Xréfs manquantes. Le dessin renvoie à d'autres fichiers DWG qui n'ont pas été envoyés. Voir DWG avec xréfs.
  • Tout est dans le modèle. Certains dessins ont des présentations vides. Regardez le dessin du modèle : le tracé intelligent y trouve les dessins séparés.
  • Objets de logiciels spécialisés. Les dessins issus des versions d'AutoCAD pour le génie civil, les fluides ou d'autres métiers peuvent contenir des objets personnalisés que d'autres logiciels ne savent pas dessiner. Demandez un PDF à l'expéditeur, ou qu'il décompose ces objets.
  • Calques gelés ou masqués. Des parties du dessin peuvent être sur des calques masqués. Vérifiez la liste des calques dans le grand aperçu.

6. Il est protégé par mot de passe

Certaines anciennes versions d'AutoCAD pouvaient enregistrer des dessins avec un mot de passe. Ils ne s'ouvrent pas sans le logiciel d'origine et le mot de passe.

7. Il est très volumineux

Un dessin de plusieurs centaines de mégaoctets peut dépasser la mémoire d'un navigateur ou d'un petit portable. Fermez les autres onglets et utilisez un ordinateur de bureau, ou demandez les feuilles utiles en PDF.
