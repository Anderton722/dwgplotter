DWG créé par une version incompatible ? Comment l'ouvrir

Si votre logiciel de CAO indique qu'un dessin a été créé par une version incompatible, le fichier a été enregistré dans un format DWG plus récent que celui que votre logiciel sait lire. Vous pouvez tout de même l'afficher, l'imprimer ou le faire convertir dans votre version.

Pourquoi cela arrive

Tous les quelques ans, AutoCAD change le format DWG. Un logiciel ouvre son propre format et les plus anciens, mais pas les plus récents. Un dessin enregistré avec AutoCAD 2018 ou plus récent (code AC1032) ne s'ouvre pas dans AutoCAD 2017 ou antérieur, et un dessin enregistré avec AutoCAD 2013 (AC1027) ne s'ouvre pas dans AutoCAD 2012.

Vérifiez le format de votre fichier avec le vérificateur de version DWG, puis comparez-le à votre logiciel dans le tableau des versions DWG.

Cinq façons de l'ouvrir

1. L'afficher et l'imprimer dans le navigateur

La visionneuse DWG gratuite lit tous les formats de R14 jusqu'au format actuel de 2018. Zoomez, vérifiez les calques et enregistrez chaque présentation en PDF. Rien n'est envoyé.

2. Demander un enregistrement dans une version antérieure

Dans AutoCAD : Fichier > Enregistrer sous, puis un format plus ancien dans « Type de fichier », par exemple « Dessin AutoCAD 2013/LT2013 ». Indiquez la version dont vous disposez.

3. Le convertir avec un convertisseur DWG gratuit

Des convertisseurs gratuits pour ordinateur réécrivent un DWG dans un format plus ancien, fichier par fichier ou par dossier. Gardez l'original : certaines fonctions récentes peuvent être simplifiées.

4. Demander un PDF ou un DXF

Pour simplement consulter ou imprimer le dessin, un PDF est plus simple. Pour le modifier dans un autre logiciel, un DXF dans une version ancienne s'ouvre dans presque tous les logiciels de CAO.

5. Mettre à jour votre logiciel

Tout AutoCAD depuis 2018 ouvre tous les DWG actuels, car le format n'a pas changé depuis 2018.

Questions

Que signifie « créé par une version incompatible » ?

Le dessin a été enregistré dans un format DWG plus récent que celui du logiciel qui essaie de l'ouvrir. Le fichier lui-même est généralement intact.

Quelle version d'AutoCAD ouvre les fichiers AC1032 ?

AutoCAD 2018 et toutes les versions suivantes. Voir AC1032.

Puis-je ouvrir un DWG récent dans un ancien AutoCAD sans le convertir ?

Non. Le fichier doit être enregistré ou converti dans un format que votre version prend en charge.
