Vérificateur de version DWG

Découvrez avec quelle version d'AutoCAD un fichier DWG ou DXF a été enregistré. Déposez le fichier ci-dessous. Seuls les premiers octets sont lus et rien n'est envoyé.

Ce que signifie le résultat

Le code de version, comme AC1027, détermine quels logiciels peuvent ouvrir un dessin. Les codes récents ne s'ouvrent pas dans les anciens logiciels. La liste complète est dans les versions DWG expliquées.

  • AC1032 (format 2018) est utilisé par toutes les versions d'AutoCAD depuis 2018.
  • AC1027 (format 2013) est utilisé par les versions 2013 à 2017.
  • AC1024 (format 2010) est utilisé par les versions 2010 à 2012.

Questions

Mon fichier est-il envoyé ?

Non. Le vérificateur lit le début du fichier dans votre navigateur et rien n'est envoyé.

Quelle version d'AutoCAD faut-il pour l'ouvrir ?

Toute version à partir de celle indiquée. Par exemple, un fichier AC1027 s'ouvre dans AutoCAD 2013 et suivants. Pour le consulter sans AutoCAD, utilisez la visionneuse DWG gratuite.

Le fichier n'est pas reconnu. Et maintenant ?

Voir le fichier DWG ne s'ouvre pas pour les causes habituelles.
