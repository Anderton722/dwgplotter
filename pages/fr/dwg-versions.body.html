Les versions DWG expliquées

Tous les quelques ans, le format DWG change. Chaque version a un code, comme AC1015 ou AC1032, inscrit tout au début du fichier. Cette page les liste et explique ce qu'elles signifient pour l'ouverture d'un dessin.

Pourquoi la version compte

  • Les fichiers récents ne s'ouvrent pas dans les anciens logiciels. Un dessin au format 2018 ne s'ouvre pas dans AutoCAD 2017 ni dans les logiciels limités au format 2013.
  • Les vieux fichiers peuvent ne pas s'ouvrir dans les visionneuses récentes. Beaucoup d'outils modernes, dont celui-ci, commencent à R14.
  • Le format change moins souvent que le logiciel. AutoCAD 2024 enregistre toujours au format 2018 : « un fichier 2024 » est un fichier AC1032.

Comment connaître la version d'un fichier

  1. Le plus rapide : déposez-le dans le vérificateur de version DWG. Il ne lit que les premiers octets et rien n'est envoyé.
  2. À la main : ouvrez le fichier dans un éditeur de texte. Les six premiers caractères sont le code, par exemple AC1027.
  3. Pour un fichier DXF, la version se trouve après $ACADVER, près du début du fichier.

Comment enregistrer un DWG dans une version antérieure

Dans AutoCAD, utilisez Enregistrer sous et choisissez un type « Dessin AutoCAD 20xx » plus ancien, ou réglez la valeur par défaut dans les options Ouvrir et enregistrer. Les autres logiciels de CAO ont un réglage similaire. Sans logiciel de CAO, demandez-le à l'expéditeur ou convertissez le dessin en PDF.
