Comment ouvrir un fichier DWG sur Mac

macOS ne sait pas ouvrir les dessins DWG, et Aperçu n'affiche qu'une icône vide. La solution la plus rapide ne demande aucun téléchargement : ouvrez le dessin dans votre navigateur.

Ouvrir un DWG dans Safari ou Chrome

Option 1 : dans le navigateur (sans installation)

  1. Ouvrez DWG Plotter dans Safari, Chrome, Firefox ou Edge.
  2. Faites glisser le fichier DWG depuis le Finder sur la page, ou cliquez pour le choisir.
  3. Toutes les feuilles s'affichent. Cliquez sur l'une d'elles pour zoomer, afficher ou masquer des calques, ou mesurer.
  4. Pour garder une copie lisible partout, cliquez sur Télécharger le PDF. Le PDF s'ouvre dans Aperçu.

Le dessin est lu sur votre Mac et n'est pas envoyé : c'est sûr pour les dessins confidentiels et ceux des clients. Cela fonctionne aussi bien sur les Mac Intel que sur les Mac Apple silicon.

Option 2 : demander un PDF

Si vous devez seulement consulter le dessin, l'expéditeur peut exporter un PDF en une minute, avec les polices et les réglages de tracé exacts.

Option 3 : un logiciel de CAO pour Mac

Pour modifier le dessin, il faut un logiciel de CAO. AutoCAD existe en version Mac, et d'autres logiciels de CAO pour macOS lisent le DWG. La plupart sont payants et volumineux : ils ne valent la peine que si vous travaillez souvent avec des DWG.

Conseils pour Mac

  • DWG reçu par e-mail ou dans un zip ? Enregistrez-le d'abord dans Téléchargements, décompressez-le si besoin, puis faites-le glisser sur la page.
  • Plusieurs fichiers liés ? Sélectionnez-les tous dans le Finder et faites-les glisser ensemble. Voir xréfs.
  • Il ne s'ouvre pas ? Voir le fichier DWG ne s'ouvre pas.
