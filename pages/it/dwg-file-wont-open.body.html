Il file DWG non si apre? Cause e soluzioni

Quasi tutti i file DWG che non si aprono hanno uno di pochi problemi. Scorri questo elenco per trovare il tuo.

Prova ad aprirlo qui

1. Il download è incompleto o danneggiato

La posta elettronica e le app di messaggistica a volte troncano o bloccano gli allegati DWG. Controlla la dimensione: un disegno di pochi kilobyte, o di 0 byte, è rovinato. Chiedi di rimandarlo, compresso in zip o tramite un link di condivisione.

2. È ancora compresso

I disegni arrivano spesso in un file zip (un pacchetto eTransmit), a volte con un nome che finisce in .dwg.zip. Estrai prima lo zip, poi apri i file DWG che contiene.

3. La versione è troppo vecchia, o troppo nuova per il tuo programma

Ogni qualche anno AutoCAD cambia il formato DWG. I programmi più vecchi non aprono i file salvati in un formato più recente, e i file molto vecchi (R13 e precedenti) non sono supportati da molti visualizzatori moderni. Usa la verifica versione DWG per sapere in che formato è il file. Il nostro visualizzatore apre i formati da R14 all'attuale 2018. Se hai un programma più vecchio, chiedi al mittente di salvare il disegno in una versione precedente.

4. Non è davvero un DWG, o è danneggiato

Alcuni altri programmi usano l'estensione .dwg per file che non c'entrano nulla. La verifica versione ti dice se il file non è un disegno AutoCAD. Se il programma mostra "Drawing file is not valid" (file di disegno non valido), il file è quasi sempre danneggiato o incompleto: prova il file .bak nella stessa cartella, rinominato in .dwg, oppure il comando RECOVER di AutoCAD.

5. Si apre ma sembra vuoto o incompleto

  • Mancano gli xref. Il disegno è collegato ad altri file DWG che non ti sono stati inviati.
  • È tutto nel modello. Alcuni disegni hanno layout vuoti. Guarda il disegno del modello: lo Smart plot trova i singoli disegni al suo interno.
  • Oggetti di software specialistici. I disegni delle versioni di AutoCAD per infrastrutture, impianti e altri settori possono contenere oggetti personalizzati che altri programmi non sanno disegnare. Chiedi al mittente un PDF, o di esplodere quegli oggetti.
  • Layer congelati o spenti. Parti del disegno possono trovarsi su layer spenti. Controlla l'elenco dei layer nell'anteprima grande.

6. È protetto da password

Alcune vecchie versioni di AutoCAD potevano salvare i disegni con una password. Questi file non si aprono senza il programma originale e la password.

7. È molto grande

Un disegno di centinaia di megabyte può superare la memoria del browser o di un portatile piccolo. Chiudi le altre schede e usa un computer fisso, oppure chiedi in PDF solo le tavole che ti servono.

Domande

Perché il mio file DWG si apre vuoto?

Di solito i layout sono vuoti e il disegno è nel modello, oppure mancano gli xref, oppure contiene oggetti di software specialistici.

Come apro un DWG senza AutoCAD?

Con il visualizzatore DWG gratuito di questo sito, direttamente nel browser. Puoi anche salvare il disegno in PDF.
