Verifica versione DWG

Scopri con quale versione di AutoCAD è stato salvato un file DWG o DXF. Trascina il file qui sotto. Vengono letti solo i primi byte e non viene caricato nulla.

Cosa significa il risultato

Il codice di versione, come AC1027, decide quali programmi possono aprire un disegno. I codici più recenti non si aprono nei programmi più vecchi.

  • AC1032 (formato 2018) è usato da tutte le versioni di AutoCAD dal 2018 a oggi.
  • AC1027 (formato 2013) è usato dalle versioni dal 2013 al 2017.
  • AC1024 (formato 2010) è usato dalle versioni dal 2010 al 2012.
  • AC1021 (formato 2007) è usato dalle versioni dal 2007 al 2009.
  • AC1018 (formato 2004) è usato dalle versioni dal 2004 al 2006.
  • AC1015 (formato 2000) è usato dalle versioni 2000, 2000i e 2002.

Domande

Il mio file viene caricato?

No. La verifica legge l'inizio del file nel tuo browser e non viene inviato nulla.

Quale versione di AutoCAD mi serve per aprirlo?

Qualsiasi versione a partire da quella indicata nel risultato. Per esempio, un file AC1027 si apre in AutoCAD 2013 e successivi. Per vederlo senza AutoCAD, usa il visualizzatore DWG gratuito.

Il file non viene riconosciuto. E adesso?

Leggi il file DWG non si apre per le cause più comuni.
