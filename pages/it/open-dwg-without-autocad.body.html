Come aprire un file DWG senza AutoCAD

DWG è il formato di disegno di AutoCAD. Se qualcuno ti ha mandato una pianta o un progetto in DWG e non hai il programma, puoi aprirlo gratis, direttamente nel browser.

Apri un DWG nel browser

Opzione 1: aprirlo nel browser

DWG Plotter legge il file sul tuo computer, mostra ogni tavola (layout) e il disegno del modello, e salva il disegno in PDF. Nell'anteprima grande puoi zoomare, accendere e spegnere i layer e misurare le distanze. Non viene caricato nulla su un server, quindi va bene anche per progetti di clienti o riservati. Funziona su Windows, Mac e Chromebook, senza installare niente e senza registrazione.

Opzione 2: chiedere un PDF

Chi ti ha mandato il disegno di solito può esportare un PDF in un minuto. È la strada migliore quando ti serve la tavola esattamente come è stata stampata, con i font e le impostazioni di stampa giusti. Se non è possibile, il visualizzatore qui sopra è l'alternativa più rapida.

Opzione 3: un visualizzatore gratuito di Autodesk

Autodesk, il produttore di AutoCAD, offre modi gratuiti per vedere i file DWG, come un visualizzatore per Windows e uno online. Possono richiedere un'installazione o un account Autodesk, e i visualizzatori online caricano il file, quindi controlla le condizioni se il disegno è riservato.

Passo per passo nel browser

  1. Trascina il file DWG nel riquadro in cima a questa pagina, oppure fai clic per sceglierlo.
  2. Ogni layout compare come miniatura, insieme al disegno del modello.
  3. Fai clic su una miniatura per aprirla in grande. Usa la rotellina o il pizzico per zoomare.
  4. Per conservarle o stamparle, salva le tavole in PDF.

Cosa puoi e non puoi fare senza AutoCAD

  • Puoi vedere il disegno, zoomare, controllare i layer, misurare e stampare o salvare in PDF.
  • Non puoi modificare il disegno. Per modificarlo serve un programma CAD.

Domande

Come aprire un file DWG gratis?

Trascina il file nel visualizzatore DWG gratuito di questo sito. Si apre nel browser, senza installazione e senza registrazione, e il file non lascia il tuo computer.

Perché il file DWG non si apre?

Le cause più comuni sono un download incompleto, un file ancora compresso in zip, la versione del DWG o riferimenti esterni mancanti. Vedi il file DWG non si apre.

Mancano parti del disegno. Cosa faccio?

Il disegno può essere collegato ad altri file DWG (xref). Chiedi questi file a chi te l'ha mandato e trascinali tutti insieme.

Con quale versione di AutoCAD è stato salvato il file?

Usa la verifica versione DWG. Il nostro visualizzatore apre dal formato R14 fino all'attuale formato 2018.

Cos'è un file DWG?

Un disegno tecnico di AutoCAD o di un altro programma CAD, come una pianta. Vedi cos'è un file DWG.
