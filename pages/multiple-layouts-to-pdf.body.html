Print every layout into one PDF

A DWG often holds a whole drawing set: plans, elevations, sections and details, each on its own layout tab. Save all of them as one multi-page PDF in a single step, free and without AutoCAD.

Open your DWG

How to plot all layouts to one PDF

  1. Open the converter and drop in the DWG file.
  2. Every layout in the file is listed, in the same order as the tabs in the drawing. Click Select all, or tick only the sheets you need.
  3. Keep Combined selected to get a single PDF, or choose Separate to get one PDF per sheet in a zip file.
  4. Click Download PDF.

Each sheet at its own size

Every page of the PDF keeps the paper size of its layout. An A1 general arrangement stays A1 and an A3 detail sheet stays A3, so the set prints at the right scale. If you would rather have every page the same size, choose A4, A3, A2 or A1 under More options, and each sheet is fitted to it.

Why not print the tabs one by one?

Printing each layout separately and joining the PDFs afterwards takes time and needs a second program. Here the sheets are combined for you in one step, in the same order as the layout tabs.

Questions

Is there a limit on the number of sheets?

No. Large sets with dozens of layouts work. They just take a little longer.

Can I include the model drawing too?

Yes. The model is listed alongside the layouts. If it holds several drawings, Smart plot lists each one separately.

Are linked drawings (xrefs) included?

Yes, if you drop the linked files in together with the main drawing. See DWG to PDF with xrefs.
