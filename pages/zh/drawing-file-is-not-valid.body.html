“图形文件无效”：原因与解决方法

当 AutoCAD 等 CAD 软件无法读取 DWG 时，会提示“图形文件无效”（Drawing file is not valid）。通常是文件损坏、不完整，或者根本不是真正的 DWG。下面教您判断属于哪种情况，并找回图纸。

在这里尝试打开文件

先确认文件是什么

把文件拖进 DWG 版本检查器。它只在浏览器中读取文件开头的几个字节。

  • 显示版本代码（如 AC1032 或 AC1027）：这是真正的 DWG，损坏在文件内部。请看下面的解决方法。
  • 提示不是图纸：文件被截断、改过名、被压缩，或是其他类型的文件。请看“文件其实不是 DWG”。

常见原因

为什么 DWG 会提示“图形文件无效”？

最常见的原因有：下载或邮件附件不完整；保存时软件崩溃或网络中断；把其他文件改名成了 .dwg；以及用不能正确写入 DWG 格式的软件保存的文件。

是因为文件版本太新吗？

通常不是。版本太新的文件一般会出现另一条关于版本不兼容的提示。请看 DWG 由不兼容的版本创建。

解决方法（从快到慢）

1. 重新获取一份文件

查看文件大小。0 字节或只有几 KB 的图纸已经损坏。请对方重新发送，最好压缩后发送或使用网盘链接，因为邮件系统有时会截断或拦截 DWG 附件。

2. 换一个软件打开

不同软件读取损坏文件的方式不同。试试免费 DWG 查看器：如果能打开，立即另存为 PDF。

3. 使用备份文件

AutoCAD 会把上一次保存的内容存为同一文件夹中的 .bak 文件。复制它，把扩展名从 .bak 改为 .dwg 后打开。只会丢失上次保存之后的修改。

4. 查找自动保存文件

自动保存文件以 .sv$ 结尾，位于软件选项中设置的临时文件夹里。复制一个，改名为 .dwg 后打开。

5. 在 AutoCAD 中运行“修复”

如果您有 AutoCAD 或类似的 CAD 软件，请使用 RECOVER（修复）命令代替普通打开。它会尽量修复并列出修复内容。之后再运行 AUDIT（核查）。

6. 插入到新图纸中

如果修复失败，新建一张图纸，把损坏的文件作为块插入或作为外部参照附着。文件头损坏时，这样有时能找回图形。

文件其实不是 DWG

  • 文件被压缩了。像 drawing.dwg.zip 这样的名字，或实际上是 zip 的文件，需要先解压。
  • 是另一种 .dwg。少数无关的软件也使用 .dwg 扩展名。
  • 是改了名的 DXF 或 PDF。把扩展名改回来，按该类型打开。
